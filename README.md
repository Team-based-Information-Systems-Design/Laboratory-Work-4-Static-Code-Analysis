# Laboratory-Work-4-Static-Code-Analysis
Выбрать и установить один из статических анализаторов кода для языка Java (встроенный в среду программирования, SpotBugs, PMD, PVS-Studio, SonarQube, Solar inCode или другой), который поддерживается в используемой вами среде программирования. Использовать выбранный статический анализатор кода для выполнения трех заданий.
